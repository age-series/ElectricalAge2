# ELN2
This is the home of ELN2, a Minecraft mod that simulates physical systems such as electric circuits, thermal systems and kinetic networks.

## Community Links

* Eln1 Discord: [https://discord.gg/YjK2JAD](https://discord.gg/YjK2JAD)

## Game Support

Supports Minecraft 1.20.1, and might target later versions in the future.
